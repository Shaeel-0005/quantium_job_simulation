# Quantium Data Analytics Job Simulation

## Overview
This repository contains my completed work for the Quantium Data Analytics Job Simulation. The project focuses on solving real-world business problems using data analytics, customer insights, and visualization techniques.

Through this simulation, I worked on analyzing retail transaction data, identifying customer purchasing behaviors, and generating actionable business recommendations.

---

## Project Objectives
- Analyze customer transaction datasets
- Clean and preprocess raw data
- Identify trends and customer segments
- Perform exploratory data analysis (EDA)
- Generate business insights using data visualization
- Support data-driven decision making
